# 游戏行业岗位需求分析 / Game Industry JD Analysis

> 用爬虫和 NLP 分析国内头部游戏公司公开招聘岗位的真实技能要求

## 背景

作为正在准备转型进入游戏行业的数据科学硕士，我需要回答一个问题：
**头部游戏公司到底要求什么技能？**

与其听他人转述，不如自己用数据说话。

## 方法

1. 爬取腾讯/米哈游/网易/莉莉丝等头部公司公开发布的策划岗 JD
2. 对任职要求做中文分词、词频分析
3. 按硬技能 / 领域知识 / 软技能 / 资历四类归类
4. 对照自己的背景找差距

## 数据规模

- 腾讯：167 个岗位
- 米哈游：xx 个岗位（待补）
- ……

## 主要发现（腾讯）

- 75% 岗位在深圳
- 99% 集中在 IEG 互动娱乐事业群
- 沟通能力（74次）、热爱游戏（46次）是几乎全员要求
- UE/Unreal Engine 是最高频硬技能（86次）
- ……

## 文件说明

- `tencent_scraper.py`：腾讯列表爬虫
- `tencent_details.py`：详情补全爬虫
- `analyze_jds.py`：词频分析脚本
